# Sri Lanka Landing (starter)

Place two images in the project folder with these filenames:

- `pic01.jpg` — starter/side-view island (used on landing)
- `pic02.jpg` — detail view with text overlay (used after entering)

How to run:

1. Open the folder in a browser directly, or run a quick static server:

```bash
cd "location of the project folder"
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```

Notes:
- The landing page has subtle animated water and foliage overlays.
- Click or tap anywhere on the landing screen to trigger the "fall/enter" animation and reveal the detail view.
- Tweak `styles.css` and replace the placeholder text in `index.html` as needed.
